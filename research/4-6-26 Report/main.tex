\begin{frame}{Abstract}
\small
Long-form podcasts are rich in information, but they are also difficult to consume quickly. This study addresses that gap through \textbf{CARD}, a framework that shortens multi-speaker audio while trying to keep the conversation understandable, speaker-grounded, and natural to listen to [4].

\vspace{0.5em}
\begin{block}{Current progress in one view}
\begin{itemize}
  \item The pipeline now supports \textbf{duration-bounded drafting}, \textbf{speaker-grounded resynthesis}, and \textbf{interjection refinement} in one end-to-end workflow [4].
  \item The strongest benchmark result so far is the \textbf{matched 10-sample-per-provider SPoRC comparison} at the 5-minute preset [1], [4].
  \item Human evaluation is already underway, but the listener study is still incomplete, so this presentation reports only \textbf{current response progress and score trends}, not final claims [7].
\end{itemize}
\end{block}
\setframebib{[1] Litterer et al., ``Mapping the Podcast Ecosystem with the Structured Podcast Research Corpus,'' ACL, 2025. \quad [4] Agustin et al., \textit{CARD}, current IEEE manuscript draft, 2026. \quad [7] Internal listener-response log, Apr. 2026.}
\end{frame}

\begin{frame}{Introduction}
\small
\begin{columns}[T,totalwidth=\textwidth]
\column{0.56\textwidth}
\begin{itemize}
  \item Podcasts are often long, informal, and highly conversational, so the listener must spend a large amount of time to get the main ideas [1], [4].
  \item A plain text summary is faster to read, but it removes the voice, pacing, overlap, and speaker identity that make podcast audio engaging [4].
  \item For this reason, the study treats summarization not only as a language problem, but also as an \textbf{audio preservation problem}.
\end{itemize}

\begin{block}{Why this matters}
The project is trying to make podcast listening more efficient without reducing the result to a flat transcript or a list of bullet points.
\end{block}

\begin{block}{Position of the study}
\begin{itemize}
  \item The task is not to generate a new podcast from scratch.
  \item The task is to compress an existing one while keeping its conversational identity.
\end{itemize}
\end{block}

\begin{frame}{Problem Statement \& Objectives}
\small
\begin{block}{Main problem}
Existing summarization approaches do not handle the full trade-off between \textbf{time compression} and \textbf{audio fidelity} well enough for conversational podcasts [4].
\end{block}

\begin{columns}[T,totalwidth=\textwidth]
\column{0.33\textwidth}
\begin{block}{Objective 1}
Keep the summary close to a user-selected runtime such as 30 seconds, 1 minute, or 5 minutes.
\end{block}

\column{0.33\textwidth}
\begin{block}{Objective 2}
Keep speakers recognizable by grounding resynthesis on source-linked references and affect cues.
\end{block}

\column{0.33\textwidth}
\begin{block}{Objective 3}
Improve realism by repairing backchannels and overlap timing instead of leaving them fully unconstrained.
\end{block}
\end{columns}
\setframebib{[4] Agustin et al., \textit{CARD}, current IEEE manuscript draft, 2026.}
\end{frame}

\begin{frame}{Discussion}
\small
\begin{columns}[T,totalwidth=\textwidth]
\column{0.54\textwidth}
\begin{block}{What the results suggest}
\begin{itemize}
  \item The benchmark evidence already shows that CARD can support controlled comparison across providers and duration settings [4].
  \item The early human scores suggest that the framework is already \textbf{pleasant and understandable overall}, but the shorter outputs still sound more compressed and rushed than the target quality level [7].
  \item This means the remaining challenge is no longer basic feasibility. It is mainly about improving how short summaries keep nuance, pacing, and conversational texture.
\end{itemize}
\end{block}

\column{0.46\textwidth}
\begin{block}{Current limitations}
\begin{itemize}
  \item Human evaluation is still incomplete.
  \item Some podcast-duration cells still have no listener response yet.
  \item Audio comments still mention rushed pacing, occasional monotony, and a few awkward transitions.
\end{itemize}
\end{block}

\begin{alertblock}{Interpretation for this report}
At this point, it is fair to say that the project has a working and benchmarked framework, while the listener study is still building the final evidence for user-facing quality.
\end{alertblock}
\end{columns}

\begin{frame}{Conclusion and Recommendation}
\small
\begin{block}{Conclusion}
The project has already moved beyond a proof-of-concept stage. The current state includes a complete four-stage pipeline, a matched benchmark with 10 retained samples per provider, a clear trend across 30-second, 1-minute, and 5-minute settings, and an active listener study that is beginning to show where the framework is already strong and where it still needs refinement.
\end{block}

\begin{block}{Recommended next steps}
\begin{itemize}
  \item Finish the remaining human-evaluation responses so that the listener-side analysis becomes complete.
  \item Prioritize improvements for \textbf{30-second outputs}, since they currently show the clearest signs of over-compression.
  \item Keep the matched benchmark protocol fixed so future revisions can be compared against the same retained 10-sample evidence base.
\end{itemize}
\end{block}
