\begin{frame}{Abstract}
\setframebib{\refSPORC\\\refHumanEval}
\small
Long-form podcasts are rich in information, but they are also difficult to consume quickly. This study addresses that gap through \textbf{CARD}, a framework that shortens multi-speaker audio while trying to keep the conversation understandable, speaker-grounded, and natural to listen to.

\vspace{0.5em}
\begin{block}{Current progress in one view}
\begin{itemize}
  \item The pipeline now supports \textbf{duration-bounded drafting}, \textbf{speaker-grounded resynthesis}, and \textbf{interjection refinement} in one end-to-end workflow.
  \item The strongest benchmark result so far is the \textbf{matched 10-sample-per-provider SPoRC comparison} at the 5-minute preset [1].
  \item Human evaluation is already underway, but the listener study is still incomplete, so this presentation reports only \textbf{current response progress and score trends}, not final claims [5].
\end{itemize}
\end{block}
\end{frame}

\begin{frame}{Introduction}
\setframebib{\refSPORC}
\small
\begin{columns}[T,totalwidth=\textwidth]
\column{0.56\textwidth}
\begin{itemize}
  \item Podcasts are often long, informal, and highly conversational, so the listener must spend a large amount of time to get the main ideas [1].
  \item A plain text summary is faster to read, but it removes the voice, pacing, overlap, and speaker identity that make podcast audio engaging.
  \item For this reason, the study treats summarization not only as a language problem, but also as an \textbf{audio preservation problem}.
\end{itemize}

\begin{block}{Why this matters}
The project is trying to make podcast listening more efficient without reducing the result to a flat transcript or a list of bullet points.
\end{block}

\begin{frame}{Problem Statement \& Objectives}
\setframebib{}
\small
\begin{block}{Main problem}
Existing summarization approaches do not handle the full trade-off between \textbf{time compression} and \textbf{audio fidelity} well enough for conversational podcasts.
\end{block}

\begin{columns}[T,totalwidth=.96\textwidth]
\column{0.30\textwidth}
\begin{block}{Objective 1}
Keep the summary close to a user-selected runtime such as 30 seconds, 1 minute, or 5 minutes.
\end{block}

\column{0.30\textwidth}
\begin{block}{Objective 2}
Keep speakers recognizable by grounding resynthesis on source-linked references and affect cues.
\end{block}

\column{0.30\textwidth}
\begin{block}{Objective 3}
Improve realism by repairing backchannels and overlap timing instead of leaving them fully unconstrained.
\end{block}
\end{columns}
\end{frame}

\begin{block}{How it works}
{\fontsize{6.4}{7}\selectfont
\begin{itemize}
  \item Separation reduces non-speech noise before ASR and speaker-reference extraction.
  \item ASR and diarization are reconciled into one segment list: \texttt{speaker}, \texttt{start\_time}, \texttt{end\_time}, and \texttt{text}.
  \item Segment extras are retained for later stages, including overlap hints, source-audio pointers, and affect vectors.
  \item The output is the evidence layer used by Stage 2 for drafting and by Stage 3 for voice grounding.
\end{itemize}
}

{\fontsize{5.85}{6.45}\selectfont Russell's valence--arousal plane supplies the directional intuition: right is more positive; up is more activated.}

\column{0.58\textwidth}
\begin{block}{Mapping thought process}
{\fontsize{6.15}{6.75}\selectfont
\begin{enumerate}
  \item \textbf{Categorical scores} say which emotion label the audio resembles.
  \item \textbf{Valence} routes energy toward positive or negative channels.
  \item \textbf{Arousal} decides whether the delivery should be active or calm.
  \item \textbf{Dominance} only refines negative active speech: high dominance favors anger; low dominance favors fear/sadness.
\end{enumerate}
}
\end{block}
\vspace{0.1em}
{\fontsize{5.65}{6.25}\selectfont
\begin{tabularx}{\linewidth}{p{2.0cm}Y}
\toprule
Direction & Implementation push \\
\midrule
positive + active & \(happy += val(0.45+0.55aro)w_d\); \(surprised += val\,aro\,\beta_s w_d\) \\
positive + calm & \(calm += (1-aro)(0.3+0.7val)w_d\) \\
negative + active & \(angry += (1-val)aro\,dom\,\beta_a w_d\); \(afraid += (1-val)aro(1-dom)\beta_f w_d\) \\
negative + calm & \(sad, melancholic += (1-val)(1-aro)\) terms \\
stability controls & add calm floor, cap dominant channel, apply IndexTTS bias, clamp total intensity \\
\bottomrule
\end{tabularx}
}
\end{columns}
\end{frame}

\begin{frame}{Discussion}
\setframebib{\refHumanEval}
\small
\begin{columns}[T,totalwidth=\textwidth]
\column{0.52\textwidth}
\begin{block}{What the results suggest}
{\scriptsize
\begin{itemize}
  \item The benchmark evidence already shows that CARD can support controlled comparison across providers and duration settings.
  \item The early human scores suggest that the framework is already \textbf{pleasant and understandable overall}, but the shorter outputs still sound more compressed and rushed than the target quality level [5].
  \item This means the remaining challenge is no longer basic feasibility. It is mainly about improving how short summaries keep nuance, pacing, and conversational texture.
\end{itemize}
}
\end{block}

\column{0.48\textwidth}
\begin{block}{Current limitations}
{\scriptsize
\begin{itemize}
  \item Human evaluation is still incomplete.
  \item Some podcast-duration cells still have no listener response yet.
  \item Audio comments still mention rushed pacing, occasional monotony, and a few awkward transitions.
\end{itemize}
}
\end{block}

\begin{alertblock}{Interpretation for this report}
{\scriptsize The project already has a working and benchmarked framework, while the listener study is still building the final evidence for user-facing quality.}

\begin{frame}{Conclusion and Recommendation}
\setframebib{\refSPORC\quad\refHumanEval}
\small
\begin{block}{Conclusion}
The project has already moved beyond a proof-of-concept stage. The current state includes a complete four-stage pipeline, a matched benchmark with 10 retained samples per provider, a clear trend across 30-second, 1-minute, and 5-minute settings, and an active listener study that is beginning to show where the framework is already strong and where it still needs refinement.
\end{block}

\begin{block}{Recommended next steps}
\begin{itemize}
  \item Finish the remaining human-evaluation responses so that the listener-side analysis becomes complete.
  \item Prioritize improvements for \textbf{30-second outputs}, since they currently show the clearest signs of over-compression.
  \item Keep the matched benchmark protocol fixed so future revisions can be compared against the same retained 10-sample evidence base.
\end{itemize}
\end{block}
