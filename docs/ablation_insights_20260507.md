# SPoRC Ablation Notes - 2026-05-07

Basis: complete six-cell SPoRC matrix with 20 retained samples per cell. The
later 100-sample extension was partial at the time these notes were written, so
keep it out of final claims.

## Initial Read

1. Factualness stays in a tight band, roughly `0.679` to `0.712`, with
   overlapping confidence intervals. Frame the result as practical parity unless
   a larger extension separates the variants.
2. Removing the critic kept factualness close while cutting tool calls:
   thinking went from `14.9` to `11.2`, and nonthinking went from `21.4` to
   `17.1`.
3. Memory has no clean main effect in the historical matrix. With thinking,
   no-memory rose from `0.679` to `0.712`; without thinking, no-memory dropped
   from `0.712` to `0.687`.
4. Thinking alone explains little variation. The best factualness was shared by
   nonthinking baseline and thinking no-memory.
5. Fluency is ahead of factual coverage. Judges can call a summary smooth while
   still saying it skips major topics or compresses too aggressively.
6. The core observed failure mode is overcleaned compression. Across judge
   rationales, `filler` appeared 107 times and `compress` appeared 77 times.

condition unless they are regenerated with an isolated `max_iterations=0`
